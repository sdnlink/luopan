# 玄空理气出处随结果匹配

## 问题与修复

九星分析卡原先始终调用 `chart.analysisNote`，后者返回包含全部经典格局及二五、五黄文字的固定说明，没有所选宫位或流年流月参数。八宅、紫白、奇门、三合也有整套口诀重复附在单项判断之后的问题。

本轮统一使用 `TraditionalEvidence` 表达来源、原文、命中条件和原文链接。每次展开九星依据时，由所选宫位、山向星、年星、月星及当前格局生成来源，不保存上次选择的出处文案。

- 九星：匹配山向、山/年、向/年、山/月、向/月、年/月六组关系。相同来源合并展示，保留各命中组合与不同原文。未知宫位或无效客星不沿用旧结果。
- 一颗5仅匹配五黄规则；5/5才匹配重叠；2/5、5/2才匹配二五同宫。1/6配属修正为金水相生。
- 整体格局只列当前判定；三般卦和七星打劫仅在实际匹配时加入，七星打劫宫位依据只出现在对应三宫。
- 独立宫位解释及天机书综合、财富、健康、布局说明同步使用相应盘面和实际选中的目标宫位来源。
- 八宅：显示当前星曜的配属规则，不再在每个方向列全部八星。
- 紫白：年、月星与建议分支一起决定来源，不再把八白、九紫和五黄固定串在一起。
- 奇门：显示当前门及所在宫的规则类别。
- 三合：八路黄泉按当前向首匹配具体条目，非命中向首使用独立说明；八煞标出当前坐山、卦宫、对应地支。全套口诀保留于折叠区。
- 新增44个来源词条，覆盖8种语言；原文保留原字，不把翻译或应用归纳冒充原文。
