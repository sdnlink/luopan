# 玄空格局分析：空间、时运与简洁展示

## 本轮改动

- 分析对象可选当前罗盘或当前住宅。住宅向首从当前户型/测绘读取，图纸北向和 AR 坐标基准只用于坐标换算。当前罗盘模式不自动混入房屋资料。
- 只读取当前 propertyID 对应的户型。户型向首与测绘向首相差超过 7.5° 时提示校准，暂停合并测绘标记；外部记录按绝对方位归宫。
- 房间按真实多边形或旋转矩形的 11×11 采样估算各宫覆盖；图纸计算恢复长宽比例。中宫范围采用较短边 12% 的半径。床、灶、门窗使用各自实测点，不以卧室/厨房中心代替。
- 接入 PurpleWhiteEngine 的流年流月、太岁/岁破/三煞。分析时间可精确到分钟，“今天”恢复跟随当前时间。沿用引擎的立春交岁、节气交月，每分钟刷新，重新进入页面时刷新时间。
- 山向、山/年、向/年、山/月、向/月、年/月分别求五行关系。81 种有序星数组合均可计算相同、相生、相克；1/4、1/6、2/5、3/7、7/9、双9等规则加入对应的使用检查。
- 建议结合卧室/床、厨房/灶、大门、实测窗、湿区、缺角决定。卧室优先睡眠，湿区不会推荐改成书房，厨房不会推荐安静座椅，单独缺角标记只复核边界。
- 外部形煞按类型增加道路、来风、视线、热源或建筑检查。复用已有距离判级决定优先级。
- 三般卦增加全屋用途/通行复核；七星打劫按实际匹配的三宫分组，给相关方位增加联动门窗/动线检查。现场状态区分待核对、部分条件已记录、先处理冲突，不作为“实际环境已成吉局”的证明。
- 每宫可记录开阔明亮、稳固靠实、流水、持续噪音、眩光、通道受阻。未勾选代表未知。记录跟随当前房屋持久化，保存/加载宅谱及 JSON 备份保留记录，换房清空，旧编辑闭包不能写入新房。

## 展示收敛

- 首页移除引导段落，保留菜单名称与简短用途。
- 玄空首屏按综合结果显示一句结论、三个优先方位、方位图和最多三条行动；其他行动折叠。
- 方位图标注房间/实测对象，年月星数收至依据。原始飞星盘在手机默认折叠，宽屏保留左右对照。
- 星数关系、触发理由、覆盖比例、外部记录距离与传统说明统一放入“查看依据”。
- 八宅、本命卦和天星择日的使用说明、紫白客星的长篇依据默认折叠。
- 缺项只列需要补的资料，并提供户型/床灶、外部环境入口。
- 新增词条覆盖全部 8 种语言，同时清除移除的界面文案词条。

## 实际边界

覆盖比例是采样估计；旧户型没有长宽比时沿用 1:1。房间、家具、环境记录的准确性仍取决于测绘与用户校准。此轮建立了可追溯的规则与数据联动，不包含完整古籍逐条断验库、施工测量认证或实际结果预测。2/5 仍沿用产品现有的保守静用规则，未因特殊格局自动解除提示。
