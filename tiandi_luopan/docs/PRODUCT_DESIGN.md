## 1. 产品背景与审计现状

### 1.1 现有代码架构审计
现有 `tiandi_luopan` 基于 Android 原生（Kotlin）与 iOS 原生（Swift）通过 WebView (`yiijing_map.html`) 运行，底层具备扎实的技术积累：
* **传感器融合与滤波**：实现了 IMU 加速度、地磁、旋转矢量传感器融合；内置 0.15° 死区滤波、40ms 倾角限流、静止零速修正 (ZUPT) 及 WMM 世界地磁模型偏角计算；
* **离屏内存渲染**：通过 Offscreen Canvas 预渲染 350+ 个复杂矢量圆环图层，旋转时仅调用一条 GPU 贴图操作，确保 60FPS 丝滑体验；
* **天文与易学结合**：开普勒定气法推算二十四节气，Spencer 日行差方程推算当地真太阳时，四柱干支严格以立春换年、定气节令换月。

### 1.2 现有痛点与易学断层
* **理气核心缺失**：
  - 缺乏**三元九运与玄空飞星**：当前正值**下元九运 (2024-2043)**，九紫离火当令。缺乏当运九宫飞星（运盘/山星/向星）、旺山旺向与替卦下卦分析，无法完成现代阳宅的核心理气断验；
  - 缺乏**八宅明镜大游年**（东四宅/西四宅、生气延年天医伏位与绝命五鬼祸害六煞）与**杨公三合水法**（生旺墓绝十二长生）。
* **形峦与空间断层**：
  - 传统风水“峦头为体，理气为用”，现有应用纯看罗盘角度，无法对照门前室外的路冲、反弓水、壁刀煞、天斩煞等形峦冲克；
  - 缺乏室内“立极定中宫”工具，实地测得的角度无法直接投影到用户房屋户型图上。
* **信息呈现天书化**：
  - 盘面信息过密，普通业主面对六十四卦爻符产生严重的认知负荷；
  - 缺乏“大白话吉凶诊断”与“针对性行动建议”（买房能不能买、大门床头怎么放、财位在何方、五黄病符如何化解）。

### 2.1 核心价值主张
打造一款**“让专业地师无可挑剔，让普通大众一秒看懂”**的时空全息智慧罗盘。连接天时（节气/日行/真太阳时）、地利（二十四山/真磁偏角/分金/消砂纳水）、人和（玄空飞星/八宅命卦/空间落位）。

## 3. 核心信息架构与界面重构哲学

### 3.1 渐进式信息暴露原则 (Progressive Disclosure)
* **第 1 层：即时决策层（一秒定吉凶）**：大字坐向、空亡诊断徽章、九运吉凶评级、当前朝向核心职能（文昌/官禄/病符）；
* **第 2 层：空间落地层（指导行动）**：AR 镜头天心十字透视、户型图九宫叠透、八方居家化解锦囊；
* **第 3 层：专业堪舆层（地师深研）**：玄空九星飞星盘、大游年星盘、一百二十分金纳音、六十四卦方圆图、天星日课。

### 3.2 界面真正需要与重点关注的内容清单
1. **立向“定海神针”状态指示**：
   - 坐向山向精确读数（例：`坐子向午 182.5°`）；
   - **空亡状态警戒灯**：
     - 绿色：`正针纯清 (偏右 1.2°)`（磁场纯正，丁财两旺）；
     - 橙色：`兼向替卦 (子山兼癸 4.8°)`（需起替卦飞星）；
     - 红色高危报警：`【出卦大空亡 / 差错小空亡】`（线压卦界，大凶不可立向）；
2. **三元九运玄空吉凶速断**：
   - 自动给出当下格局标签：`【旺山旺向 (丁财双全)】`、`【双星到向 (旺财损丁)】`、`【双星到坐 (旺丁衰财)】`、`【上山下水 (丁财两败)】`；
3. **居家八方落地指南**：
   - 结合后天八卦与流年/运星，标定房屋核心吉凶位：**正财位、偏财位、文昌位、天医健康位、五黄大煞位、二黑病符位**；
4. **AR 实景天心透视**：
   - 手机摄像头看实景大门与远景，叠透天心十字瞄准线与水平仪，直击门窗外的形煞（天斩煞、路冲、反弓）；
5. **真太阳时日晷与四柱干支**：
   - 经度时差精确校正，解决“早晚子时”争议，作为择吉与起课基准。

### 3.3 APP 界面展示的三大核心重构原则
1. **结构形态重构：从“单页瀑布流”重构为“四大场景底栏 Tab”**
   - 划分为四大业务场景 Tab：**【罗盘】(Compass)**、**【透视】(AR Vision)**、**【户型】(Floor Plan)**、**【理气】(Feng Shui)**。
2. **信息布局重构：引入“HUD 定针抬头显示”与“可折叠抽屉 (Bottom Sheet)”**
   - 盘面上方固化 HUD 胶囊看板（大字坐向 + 空亡胶囊灯 + 九运评级）；
   - 盘面下方设立微卡片可滑动抽屉，默认只露出一张最关键的吉凶速报卡，上滑展开八方全鉴。
3. **视觉体验重构：设立“白话大众模式”与“地师专业模式”一键双态切换**
   - **白话模式**：隐藏六十四卦与分金爻象，仅展示八宫色彩与二十四山，将晦涩卦理直译为“大门纳吉气、文昌大旺、避开病符”；
   - **专业模式**：全开 9 圈同心圆，输出 120 分金纳音、六十四卦方圆图、节气弧度与替卦断诀。

## 6. 严密数学模型与术数规则规范

### 6.1 二十四山与空亡判定数学模型
设量测得到的真北航向角为 $\theta \in [0^\circ, 360^\circ)$。
* 二十四山以正北“子山”中心点为 $0^\circ$（即 $352.5^\circ \sim 7.5^\circ$ 为子山范围），每山 $15^\circ$。
* 设第 $i$ 山的中线角为 $\alpha_i = i \times 15^\circ$ ($i = 0, 1, \dots, 23$)。
* 相对偏角 $\Delta\theta = |\theta - \alpha_i|$（取圆周最小夹角）。
* **判定状态判据**：
  $$\text{空亡状态} = \begin{cases} 
  \text{正针纯清 (吉)} & \text{若 } \Delta\theta \le 4.5^\circ \\
  \text{兼向替卦 (平/需用替卦)} & \text{若 } 4.5^\circ < \Delta\theta \le 6.0^\circ \\
  \text{差错小空亡 (凶)} & \text{若 } 7.0^\circ \le \Delta\theta \le 8.0^\circ \ (\text{同卦两山交界}) \\
  \text{出卦大空亡 (大凶)} & \text{若 } \theta \text{ 位于八宫卦界 } \pm 0.5^\circ
  \end{cases}$$

### 6.2 真太阳时校正模型 (Spencer 方程)
1. **经度时差校正**：
   $$\Delta T_1 = 4 \times (\lambda_{\text{local}} - 120^\circ) \quad (\text{分钟})$$
2. **地球轨道偏心率与黄赤交角时差 ($EoT$)**：
   设年积日为 $N$，日角 $\Gamma = \frac{2\pi(N - 1)}{365}$。
   $$EoT = 229.18 \times (0.000075 + 0.001868\cos\Gamma - 0.032077\sin\Gamma - 0.014615\cos 2\Gamma - 0.040849\sin 2\Gamma)$$
3. **真实真太阳时**：
   $$T_{\text{solar}} = T_{\text{beijing}} + \Delta T_1 + EoT$$

### 6.8 动土日课天星神煞判据 (岁破/月破/坐向三煞)
* **岁破与月破判据**：
  设日课当日地支为 $D$，太岁当年年支为 $Y$，月建月支为 $M$。

## 12. 紫白九星流年流月流日动态气运演变系统

玄空飞星三元九运（运盘、山盘、向盘）构成了阳宅的**“先天命盘（体）”**；而岁月流转中的**“客星（用）”**则是引动吉凶爆发的引信。

### 12.1 三元九运年紫白九星飞临算法模型
每年正月初一非交岁之分界，必须**严格以立春交节时刻换年星入中**：
* **年紫白入中公式**：
  设公历年份为 $Y$。
  - 上元第一甲子（1864）：一白入中；
  - 中元（1924）：四绿入中；
  - 下元（1984）：七赤入中；
  - 简明通用计算公式（立春后）：
    $$\text{年星数} = (65 - (Y \pmod 9)) \pmod 9 \quad (\text{余数为 } 0 \text{ 记作 } 9)$$
    例如 2024 年（甲辰）：$(65 - (2024 \pmod 9)) = (65 - 8) = 57 \equiv 3 \pmod 9 \to$ **三碧禄存星入中**；
    2025 年（乙巳）：**二黑病符星入中**；
    2026 年（丙午）：**一白贪狼星入中**。
* **年星飞布**：中宫星定后，一律**顺飞九宫**（中 $\to$ 乾 $\to$ 兑 $\to$ 艮 $\to$ 离 $\to$ 坎 $\to$ 坤 $\to$ 震 $\to$ 巽）。

### 12.2 流月、流日客星引动与太岁/三煞轮转
* **月紫白入中法则**：
  - 子午卯酉年：正月八白、二月七赤、三月六白……（正月从八白起逆数入中，顺飞）；
  - 辰戌丑未年：正月五黄、二月四绿、三月三碧……（正月从五黄起逆数入中，顺飞）；
  - 寅申巳亥年：正月二黑、二月一白、三月九紫……（正月从二黑起逆数入中，顺飞）。
* **流年岁煞动态警示**：
  - **太岁方**：年支所在宫位（如午年太岁在正南午山），“太岁头上动土”必惹大祸；
  - **岁破方**：太岁对冲方（午年岁破在正北子山）；
  - **五黄大煞飞临方**：每年五黄星落入何宫，该宫位当年**绝对忌动土、忌钻孔敲钉、忌设红黄两色**。

### 12.3 动态气运对阳宅门、床、灶的即时冲动诊断
* **大门同论**：若本宅大门原本在向盘逢二黑，流年五黄客星又飞临该方，构成**“流年二五交加”**，系统立即在首页触发高危橙红警报：
  `【警告：今年流年五黄飞临入户门！门上务必悬挂六帝钱铜铃，出入忌大力摔门】`；

## 13. 杨公形气大成：八煞黄泉与二十四山消峰纳水秘诀

### 13.1 八路四路黄泉水法吉凶判据
杨公三合水法视水法为血脉，黄泉煞为杀人灭宅之第一毒水。罗盘内置八煞黄泉严密判据：

* **四路黄泉吉凶判据表**：

| 立向 (向首) | 忌出水/来水方位 (黄泉大煞) | 凶相断语 |
| :--- | :--- | :--- |
| **立庚向、丁向** | **坤方** 来去水 | 损成丁、绝人嗣、横生痼疾 |
| **立乙向、丙向** | **巽方** 来去水 | 妇人产厄、长房破败、风湿水肿 |

| **立辛向、壬向** | **乾方** 来去水 | 损老翁、长男投河、肺疾吐血 |

### 13.2 救贫黄泉与催官黄泉合法水法识别
并非见水皆凶，水合局反主大发：
* **救贫黄泉**：若辛向水出乾口，反而带走杀煞，金水汪洋，主“辛入乾宫百万庄”；
* **催官黄泉**：生旺水朝堂入局，主官爵晋升、发越如雷。
* **罗盘动态指引**：当用户切换至三合盘时，水口瞄准线自动提示：`【当前庚向见坤方出水，犯恶死八煞黄泉，速改门向避开！】`。

### 13.3 二十四山坐向劫煞与消砂五行生克
* **拨砂生克五大星**（以坐山五行为“我”，以周围高山、大厦峰峦为“客”）：
  1. **生砂（大吉）**：客生我，如金山见土峰，主添丁进宝、神童及第；
  2. **旺砂（吉）**：客与我同五行，如木山见木峰，主兄弟同心、资财巨万；

  5. **煞砂（大凶）**：客克我，如火山见水峰，客如利刃刺身，主车祸血光、横夭败绝。
