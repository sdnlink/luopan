# 演象 · 时空罗盘 - 微信小程序版

本工程是由 Android 原生时空罗盘完整重构移植而来的**微信小程序原生工程**。

---

## 核心特性与技术实现

1. **Canvas 2D 高保真绘图**：
   * 采用微信小程序最新的 `type="2d"` Canvas API，自动依据设备像素比（DPR）缩放，在高分辨率屏幕上丝滑细腻、毫无锯齿；
   * 完整呈现：天池太极图、后天/先天八宫环、二十四山、二十四节气、二十四小时时间刻度环、先天六十四卦圆图外环。

2. **真北与地磁北双指针高精度系统**：
   * 🟢 **绿色“磁”针**（标“磁”字）：地磁北（地盘正针），锁定物理地磁场；
   * 🟡 **金色“真”针**（标“真”字）：地理真北（卫星地图正北），经 GPS 与地磁偏角校正；
   * **地磁偏角微金虚线弧**：两针之间以虚线金色圆弧实时连接，标注当地地磁偏角（如实测北京地区 `7.8°` / 偏西）。

3. **离线全球地磁偏角运算（WMM）**：
   * `utils/geomagnetic.js` 100% 完整复刻了 Android 官方 `GeomagneticField` 球谐系数算法；
   * 小程序完全无需依赖外部网络服务器接口，即可毫秒级算出全国乃至全球任意经纬度、海拔的真实地磁偏角。

4. **界面纯粹优雅与坐标合理布局**：
   * 罗盘上方视觉空间开阔纯净，仅保留模式切换 Tab 与朝向状态微光胶囊；
   * 经纬度高精度坐标（如 `39.7627°N, 116.2064°E · 海拔 44m`）规范呈现在最下方的卦象与二十四山解释卡片中；
   * 支持触摸旋转与滑动探查：手指在罗盘上触摸滑动时，高亮选中任意山向，并在底部面板中实时呈现所属八宫、五行、当令节气及主应消息卦。

## 启动性能优化：按需注入 + 用时注入

1. **按需注入**：`app.json` 中已配置 `"lazyCodeLoading": "requiredComponents"`。
   > 注意：该字段必须写在 `app.json` 才生效。`project.config.json` 的 `setting.lazyCodeLoading`
   > 只是开发者工具的本地开关，代码质量检测读取的是 `app.json`。

2. **用时注入**：`pages/index/index.json` 中为校准弹窗组件配置了占位组件：

   ```json
   {
     "usingComponents": {
       "calib-modal": "/components/calib-modal/calib-modal"
     },
     "componentPlaceholder": {
       "calib-modal": "view"
     }
   }
   ```

   配合页面层的 `wx:if="{{showCalibModal}}"`，弹窗组件在用户首次点开前完全不进入渲染树，
   其 JS / WXML / WXSS 都不会被注入执行；首次点开时先渲染为空的占位 `view`，
   渲染流程结束后才开始注入，注入完成后替换回真实组件。

   > 基础库 2.11.1 起支持按需注入，2.11.2 起支持用时注入。
   > 请将开发者工具基础库调至 2.20.1 及以上以获得优化效果。

## 导入与调试指南

1. 打开 **微信开发者工具**（WeChat DevTools）；
2. 点击 **「导入项目」**（Import Project）；
3. **项目目录**：选择本项目根目录（即本 README 所在目录，例如 `E:\code\android\tiandi_luopan_mini_program`）；
4. **AppID**：测试阶段可选择 **「测试号」** 或填入您自己的小程序 AppID；
5. 点击 **确定** 进入编辑器与模拟器；
6. 在微信开发者工具上方工具栏点击 **「真机调试」** 或 **「预览」**，使用微信扫描二维码即可在手机上实时体验真机陀螺仪与地磁双针效果！
