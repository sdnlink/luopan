# AR 辅助装修方向

建议定位：基于真实房间尺寸的小户型局部装修规划。主流程是量房、检查家具摆放、比较方案、估算材料、导出交付。移动端可先采用“AR 量房与 3D 装修规划”的表述；沉浸式 VR 作为具备相应交互后再扩展的呈现方式。

## 市场和审核依据

Apple 官方将室内设计列为 RoomPlan 的应用场景。RoomPlan 可利用兼容设备的相机和 LiDAR 生成含尺寸与物体类型的房间模型，适合作为室内设计工作流的起点，但这不代表使用该 API 就能通过 App Review。

来源：[Apple RoomPlan](https://developer.apple.com/augmented-reality/roomplan/)。

App Store 已有成熟竞品，以下是美国区当前可检索到的开发者产品说明示例，不能据此推算整个类别的应用数量：

| 产品 | 已覆盖的方向 |
| --- | --- |
| [magicplan](https://apps.apple.com/us/app/magicplan/id427424432) | AR / LiDAR 量房、平面图、现场记录、报告与估算 |
| [Planner 5D](https://apps.apple.com/us/app/planner-5d-ai-home-design/id606173978) | 2D / 3D 户型设计、家具目录与可视化 |
| [Homestyler](https://apps.apple.com/us/app/homestyler-ai-room-planner/id601137449) | 三维室内设计、家具模型与 AR 预览 |

因此，同类竞争强。仅增加 AR 标签、基础扫房或家具摆放，并不足以证明产品差异。

Apple 的 4.3(b) 列举了 fortune telling 等类别，未单独列出装修或 AR 室内设计；但其中关于与广泛存在的应用无法区分的规则适用于此方向。应提供完整、可演示的独立用途，而不能只修改旧版的名称或隐藏原有核心功能。

来源：[Apple App Review Guidelines 4.3](https://developer.apple.com/app-store/review/guidelines/#spam)。

## 实现优先级

1. **现场尺寸能继续使用。** 已有 AR / LiDAR、手工建模、项目与导出；继续保证尺寸来源明确、实测与手工模型同时保留。
2. **装修量算可复用。** 已加入面积与周长、参数保存、材料估算、CSV 与 PDF、户型对比。用于采购准备，而非完整施工报价。
3. **带尺寸约束的家具落位。** 下一阶段新增家具尺寸输入、摆放与旋转、房间边界和家具互相重叠检查，再处理门扇开启范围与通行空间。当前代码尚未提供完整的可编辑家具布置功能。
4. **方案可比较。** 未来让同一房间保留多个装修方案，比较占用空间、可用空间和材料变化；当前已保存户型对比不等同于家具布局比较。
5. **材质预览。** 墙漆、地材与灯光可视化在前述流程稳定后增加。当前没有可直接用于上架宣传的实景换材质功能。

初期聚焦用户带着实际尺寸决策“放得下吗、还剩多少空间、要买多少材料”。家具模型库、美图渲染与沉浸式体验按需求扩展，避免先投入庞大内容资产而缺少完整使用流程。
