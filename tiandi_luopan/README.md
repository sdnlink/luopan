## 1. 设计理念与产品特色

传统风水与易学讲求“**在天成象，在地成形，在时成局**”。真正的空间方位并非孤立存在，而是与日月星辰运转、节气更替、地球磁场和观测者地理坐标密不可分。

市面上的指南针软件大多仅有简单的方向指示，而传统实体罗盘携带不便、夜晚难以识读、且无法自动修正当地地磁偏角与真太阳时差。**演象·时空罗盘**通过现代数字化工程，将**地盘正针、缝针偏角、百二十分金、易经六十四卦、开普勒天文学节气、真太阳时、双轴电子水准仪及 GPS 动态感知**融为一体，构建起高精度的时空合一量测工具。

## 2. 核心功能全景与详细解析

### 2.1 顶部综合状态栏 (时间 · 速度 · 方向)
* **展示形式**：位于界面顶端，精简排版为 `21:50 · 0 KM/H · 正东 92°`。
* **功能解析**：
  - **当前时钟**：精确到分钟的实时系统时间；
  - **实时速度 (KM/H)**：基于 GPS 多普勒频移测速与毫秒级高精度经纬度微分算法计算出的瞬时移动速度，行车、乘船或野外实地巡查时直观反映位移态势；
  - **八向粗方位与度数**：将 360° 圆周映射至 8 个主要八卦方位（正北、正南、正东、正西、东北、东南、西北、西南）与精确整型角度值。
* **核心用途**：在户外实地踏勘时，提供一目了然的综合时空态势感知，无需在多个 APP 之间频繁切换。

---

### 2.2 先天与后天八卦双模式排盘
* **切换方式**：顶部导航栏点击【后天八卦】或【先天八卦】。
* **易学原理**：
  - **先天八卦（伏羲八卦）**：以“乾南坤北，离东坎西”为体，揭示天地自然未成形时的宇宙原生阴阳对称法则。
  - **后天八卦（文王八卦）**：以“离南坎北，震东兑西”为用，顺应四时流转、五行生克，是杨公风水、玄空风水、八宅风水实战立向的基石。
* **功能体现**：
  - 切换模式后，盘面中央的八宫文字、卦象符号与九宫八卦方位同步联动翻转，同时底部的格局部件（如 `[后天] 卯山 (震宫)`）会实时变换所依附的卦宫与五行属性。
* **核心用途**：满足不同流派的实战需求，“体用互参”。勘察地形山峦气势可用先天，房屋建筑立向、排星布盘则用后天。

---

### 2.3 罗盘转动模式 (随向转 vs 锁定)
* **随向转（动态感应模式）**：
  - 手机旋转时，罗盘盘面在屏幕上实时反向旋转，使罗盘上的二十四山方位始终与现实地理环境保持空间绝对对齐。
  - **用途**：现场勘测、寻找吉方时，端平手机原地环视，罗盘即真实指引当前所对山向。
* **锁定模式（定盘立向模式）**：
  - 点击【随向转】按钮即可切换为“定盘”模式，冻结盘面角度；
  - **用途**：当测量好某个阴阳宅座向后，点击锁定，即可平稳拿给福主/委托人查看，或用于室内排龙立穴、推演玄空飞星，避免手持抖动导致数据变化。

---

### 2.4 十字天心瞄准线 (坐向同论)
* **展示形式**：贯穿罗盘中心的红宝石十字丝，屏幕正前方为 **红色向上实心三角【向】**，正后方为 **青色向下实心三角【坐】**。
* **易学原理**：传统罗盘测量讲求“十字天心”，以两条垂直的经纬线对准建筑物朝向与大门正中，即为“定针”。风水学必“坐向同论”——坐在何山、向在何山，相差整整 180°。
* **功能体现**：
  - 底部控制台实时显示当前房屋/基址的立向格局（例如：`立向格局 坐酉向卯 · 正针`）；
  - 精确计算所对山向的主导五行与纳音，指明正前方所向之山与正后方所坐之山。
* **核心用途**：门前定立向、格定来龙入首、消砂纳水。

---

### 2.5 二十四山立向与空亡诊断
* **二十四山划分**：
  - 罗盘将 360° 均匀分为 24 等份，每山占 **15°**，由十二地支（子丑寅卯辰巳午未申酉戌亥）、八干（甲乙丙丁庚辛壬癸）与四维（乾坤艮巽）组成。
* **空亡诊断系统**：
  - **正针纯清**：当朝向落在 15° 的中央 **9°** 核心区间时，磁场纯净，显示绿色标牌（如 `正针纯清 (偏右1.7°)`），主丁财两旺、气脉纯正；
  - **兼针卦线**：当朝向偏离正中 4.5° 以上、落在边缘 **3°** 时（偏向邻山），系统显示黄色预警 `兼针线 (兼xx山)`，需按照玄空下卦/替卦诀起盘；
  - **出卦大空亡 / 差错小空亡**：若恰好压在两卦交界（如坎一宫与艮八宫交界）或两山正中分界线上（误差 ±0.5°），系统将触发**红色高危报警**，诊断为“大空亡”或“小空亡”，提醒立向者此线凶险不可用，防止财败丁绝。
  - **交互式点击详解**：在底栏点击【空亡诊断】即可呼出专属详解弹窗，实时显示当前偏中线度数，并深度解析正针、兼针、小空亡、大空亡的易学原理与古传断诀。
* **核心用途**：风水立向防差错、断验吉凶之利器。

---

### 2.6 一百二十分金吉凶断诀
* **理论渊源**：
  - 将二十四山每山再细分为 5 个刻度，360° 共计 **120 分金**，每分金占 **3°**，并配以甲子纳音五行与平水干支。
* **吉凶判定算法**：
  - 根据传统分金秘诀，分金线分为“旺相”（珠宝线）与“孤虚、煞曜”（火坑线）。
  - **吉（珠宝线）**：通常为丙子旬、庚子旬中五行相生有情的分金，系统高亮显示翠绿色 `丙子分金 (旺相珠宝 (吉))`；
  - **凶（火坑线）**：为甲、戊、壬等孤虚或刑克分金，系统标红预警 `戊子分金 (孤虚火坑 (凶))`。
  - **交互式点击详解**：在底栏点击【一百二十分金】即可呼出专属详解弹窗，实时展示当前命中的分金干支（第几分金）、纳音与 3° 度数范围，并附带《天玉经》正统立向避火坑珠宝秘诀。
* **核心用途**：精确到 3° 内微调棺木朝向（阴宅）或大门门框偏角（阳宅），避开火坑、趋纳珠宝。

### 2.7 双北指针系统与地磁偏角校准 (地磁北 vs 地理真北)
* **指针展示**：
  - **绿色实线粗针（标“磁”）**：指示手机地磁传感器实测的**地磁北极**；
  - **金色实线细针（标“真”）**：指示地球自转轴正北方的**地理真北极**；
  - **两针之间的金黄色虚线弧**：标注两针相差的角度，即**当地地磁偏角（Magnetic Declination）**。
* **原理与算法**：
  - 地磁北极与地理北极并不重合，且地磁偏角随全球经纬度和时间演变。例如北京地区当前地磁偏西约 7.3°。
  - iOS 版本使用 **WMM 2025-2030 离线地磁模型**结合 GPS 经纬度/海拔计算当地磁偏角；定位尚未可用时再使用 Core Location 的真北航向作为临时兜底。
  - 界面同时输出 `磁: 正东 92° · 卯山 | 真: 正东 84° (偏西7.3°)`。
* **核心用途**：破解传统罗盘与现代建筑图纸无法对齐的难题。古时杨公设立天盘缝针就是因为发现了地磁偏角。本系统让测量者在磁方位与真方位之间任意切换对照。

### 2.8 电子双轴太极水准仪 (倾角补偿)
* **展示位置**：巧妙内嵌于罗盘正中心的阴阳太极鱼天心处。
* **功能结构**：
  - **中央十字微刻线**：基准零点；
  - **绿色虚线内圈（2.5°）**：精密平水合格圈。当气泡落在圈内时，显示绿色高光与 `✓水平良好`，表明读数处于最高精度状态；
  - **黄色虚线外圈（7.0°）**：倾角安全警戒圈。当手机倾斜超过 7° 时，气泡变为红橙色并报警，提示握持不平。
* **三维空间倾角解算**：
  - 实时读取手机陀螺仪与加速度计的横滚角（Roll）与俯仰角（Pitch）。
  - 内置**三维空间向量投影矩阵**，即便手持手机带有 30°~60° 的倾斜仰角，方向指引也不会产生欧拉角万向锁与剧烈横跳。
* **核心用途**：罗盘测量最忌“不平”。内置电子水准仪确保每次立向测量都达到国家工程测量级的基准平整度。

### 2.9 先天六十四卦方圆图与十二消息卦
* **圆图构成**：
  - 罗盘外圈排布邵雍《皇极经世》**先天六十四卦圆图**，从坤卦、复卦阳生，至乾卦、姤卦阴长，依次绘制了 64 卦的精确六爻符号（阴爻 `--`、阳爻 `——`）及卦名。
* **十二辟卦（消息卦）高亮**：
  - 特别高亮展示复、临、泰、大壮、夬、乾、姤、遯、否、观、剥、坤十二辟卦，清晰指示一年十二月及一日十二时辰的阴阳消长进退规律。
* **核心用途**：易学学者推演六十四卦时空对应关系，用于玄空大卦理气、择日择吉与易经占断。

### 2.10 开普勒定气法二十四节气体系
* **算法实现**：
  - 摒弃了简陋的平均“平气法”，严格采用现代天文学规范的**“定气法”**（以太阳视黄经每行进 15° 为一节气）。
  - 基于**开普勒行星运动第二定律与牛顿二分迭代法**逼近太阳真实黄经位置，精确到分秒级。
* **界面表现**：
  - 罗盘刻度圈上标定 24 个节气，当前所处的节气（如惊蛰、春分、秋分）会自动以亮金色高光提示。
* **核心用途**：精准判定天地气运交接时刻，指导“冬至一阳生，夏至一阴生”的气机转换。

---

### 2.11 实时真太阳时日晷系统 (黄色虚线指针)
* **特征辨识**：从盘心向外辐射的 **黄色虚线细指针（末端带有金色太阳实心小圆点）**。
* **易学与天文机理**：
  - 民用北京时间以东经 120° 平太阳为基准；然而中国幅员辽阔，各地太阳真正到达“正南中天”（正午）的时间与北京时间相差甚大。
  - 应用内置 **Spencer 日行差修正方程**，结合手机实时 GPS 经度（如 116.2°），将北京时间校正为观测点上空的**天体日晷视太阳时**。
  - 界面下方同步显示：`真太阳时 21:36:59 (经度116.2° · 时差-13.9分)`。
* **核心用途**：
  - 八字命理排四柱、尤其是判定**早子时与夜子时**的分界，必须以真太阳时为准；
  - 奇门遁甲、大六壬起课，玄空择吉选时，避免因时区时差而误入凶时。

---

### 2.12 四柱八字排盘 (干支时空流转)
* **展示位置**：控制台底部 `四柱天干地支`。
* **严格的易学历法算法**：
  - **年柱**：严格以**立春定气交节时刻**为分界，立春前为上一年干支，立春后为下一年干支（并非正月初一，符合传统命理正统）；
  - **月柱**：严格以 24 节气之“节”（立春、惊蛰、清明等）交节时刻为换月分界；
  - **日柱**：采用高氏干支换算方程与公历百年儒略日连续演算法，日夜交替无断层；
  - **时柱**：采用“五鼠遁日诀”，以**真太阳时**计算当日时辰干支。
* **核心用途**：勘测现场一键获知当前天地时空干支格局，省去查阅万年历的繁复步骤。

---

### 2.13 速度感知与地理高程信息 (KM/H)
* **测速机制**：
  - 优先利用底层硬件 GPS 卫星的多普勒频移测速（Doppler Shift），精确到 0.1 km/h；
  - 在卫星信号偶发抖动时，自动退化至毫秒级两点欧氏空间微分算法，过滤静止漂移；
* **地理坐标信息**：
  - 实时解析当前 GPS 经纬度、海拔高程（米），并进行逆地理编码展示所在行政区划。
* **核心用途**：在移动车辆、船舶上巡视山形水势或河流走势时，实时掌握行进速度与走向。

---

### 2.14 多维度独立图层管理
* **控制方式**：点击右上方【图层】按钮，呼出半透明图层控制面板。
* **独立开关组件**：
  1. 八宫大格（九宫八卦底色分割）
  2. 二十四山（地盘正针刻度圈）
  3. 一百二十分金（分金纳音干支）
  4. 先天六十四卦（卦符与卦名）
  5. 二十四节气（当令节令环）
  6. 24小时制时空圈（日晷刻度）
  7. 电子双轴水平气泡（天心水准仪）
* **核心用途**：用户可根据勘测场景需要精简盘面，例如只需测定坐向时仅保留二十四山，需要研判卦气时再展开六十四卦，避免视觉干扰。

### 2.15 强磁异常环境感应与预警
* **传感器自检**：实时监听地磁传感器原始磁通量密度矢量模长与手机硬件报告的 Accuracy 精度等级；
* **环境预警机制**：当手机靠近大型金属结构、高压电箱或强磁场扬声器时，界面将弹出黄色或红色预警图标，提醒用户“磁场受干扰，请远离铁器校准”，防止立向测量受到严重误差误导。

### 2.16 AR 实景天心透视与形煞智能标注系统 (Tab 2 全景)

## 3. 底层算法与性能架构 (60FPS 丝滑保障)

罗盘在旋转过程中需要以每秒 60 次以上的频率更新，为确保在中低端手机上都能享受极致丝滑流畅的操控体验，底层进行了多项深度优化：

```
[硬件传感器流 (80-100Hz)] 
   │
   ▼
[Android 原生层滤波] ── (0.15° 死区过滤 / 40ms 倾角限流)
   │
   ▼
[requestAnimationFrame 垂直同步合并] ── (严格对齐 60Hz 屏幕刷新)
   │
   ├─► [离屏内存画布 (Offscreen Canvas)] ──► 一次性预渲染 350+ 个复杂静态矢量图层
   │                                         (单帧仅执行一条 GPU 位图贴图，<0.5ms)
   │
   └─► [天文学算力解耦 (Kepler Engine)] ──► 节气、四柱与真太阳时脱离旋转流，
                                             改为 1 秒定时缓存刷新 (消除 99.8% 算力消耗)
```

1. **离屏内存画布（Offscreen Canvas Pre-rendering）**：
   - 盘面包含了 64 卦、120 分金、24 节气、24 山、八宫等 350 多个文字与几何弧线。若每帧重新绘制，Canvas 耗时超 25ms。
   - 现已重构为**静态图层一次性预渲染在内存离屏画布中**，旋转时 GPU 只需调用一条 `drawImage` 进行硬件加速位图旋转，单帧绘制耗时由 25ms 锐减至 **0.2ms ~ 0.5ms**。
2. **开普勒天体力学解耦与缓存**：
   - 24 节气开普勒方程与四柱干支属于时间维度数据，将其从 60Hz 罗盘旋转流中完全剥离，置入 1 秒周期的后台定时器中运算并缓存，彻底消除每秒 13 万次的高阶三角函数运算。
3. **DOM 树死区防抖（Deadband Threshold）**：
   - 为底部信息卡片设定 0.2° 变动死区阈值，微小传感器底噪不再频繁触发表单重排（Reflow）与重绘（Repaint），彻底根除 DOM Thrashing 卡顿。

本仓库现已全面提供适用于 **iPhone/iPad (iOS 16.0+)** 的原生版本与构建流程：

### 5.1 产物与工程路径

* **iOS 安装包 (IPA)**：`dist-ios/YanXiangCompass-v1.3.3.ipa`

### 5.2 资源生成与打包（重要：真实 IPA 仍需 macOS）

`build_ios.ps1` 会调用 `tools/` 下的 Python 脚本完成以下步骤：

1. 提取并生成全套高清 iOS AppIcon / PWA 图标资源；
2. 为独立 PWA 演示生成 Web 适配资源（`prepare_ios_web.py`），该资源不参与原生打包；
3. 校验已维护的 Xcode 工程（`generate_pbxproj.py` 不会重新生成或覆盖工程）；
4. 调用 `package_ipa.py` **组装并压缩**出资源结构验证包 `dist-ios/YanXiangCompass-v1.3.3.ipa`。

> **⚠️ 关于“在 Windows 上打包 IPA”的说明**
> 一个可被设备安装的、**经过 Apple 签名**的 IPA 必须依赖 macOS + Xcode（`xcodebuild` / `codesign`）或 Apple 的云构建链编译出真实的 Mach-O 可执行文件。**Windows 环境无法完成这一步。**
> 因此：若当前机器上没有由 Xcode 编译出的真实 `TiandiLuopan.app`，`package_ipa.py` 只会写入一个**占位桩二进制**并明确打印警告——该 IPA **无法安装/运行**，仅用于资源结构验证。要产出可上架/可安装的 IPA，请使用方式 2（Mac + Xcode）或方式 3（GitHub Actions 云端 macOS Runner）。

在 Windows 终端执行（仅用于资源生成与占位包验证）：
```powershell
.\build_ios.ps1
```
