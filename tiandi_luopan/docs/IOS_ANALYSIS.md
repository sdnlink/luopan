# iOS 工程分析与实现说明

## 本轮修复（2026-10-28）

- 修正 Xcode 工程的本地化区域清单，加入 `en`、`zh-Hans` 和 `zh-Hant`，并将开发区域统一为实际存在的 `zh-Hans.lproj`，确保三个 `.lproj` 资源在 Xcode 与归档产物中均被识别。
- 统一发布版本为 `1.3.0 (130)`。工程构建设置是唯一版本来源，`Info.plist` 改为读取 `MARKETING_VERSION` 与 `CURRENT_PROJECT_VERSION`，避免设置页、归档元数据和安装包版本不一致。
- 修复 `tools/generate_pbxproj.py` 会用只包含四个旧 Swift 文件的模板覆盖现有工程的问题；现在检测到已存在的工程会保留其完整 Sources/Frameworks 配置，缺失工程时直接报错，避免生成不可编译的 iOS 项目。
- 将 `InfoPlist.strings` 的简体、繁体和英文资源加入 Xcode 的 `PBXVariantGroup` 与 Resources 构建阶段；隐私授权提示和系统应用名称现在会随系统语言正确本地化。
- 修正 Swift 符号审计脚本的工作目录依赖，并识别 `private(set)` 的已发布状态；从仓库根目录或 `tiandi_luopan` 目录运行时都能得到一致结果，缺失成员会让检查失败。
- 修复年度购买交易延迟到达时的权益边界：如果 StoreKit 在网络恢复后才回调一个已完成但很早的交易，会员周期从当前时间或现有未过期周期开始，不会出现“购买成功后立即过期”。
- 移除地磁模型与择日警告链路中的不必要强制解包，异常日期组件或未来规则扩展不会因可选值异常导致应用崩溃。
- 修复奇门九宫英文与繁体显示仍混入简体卦名的问题，宫位方向、卦名和中宫标签现在按当前语言完整转换。
- 修复玄空飞星英文九宫格仍显示中文方位的问题，英文页面现在显示 North、Southwest、East 等完整方向名称。
- 修复户型页“重置示例”只清除图片但保留拖拽房间位置的问题；现在会同时恢复示例房间、中宫立极点和编辑状态，当前已购买的访问权益不会被错误退回。
- 修复三合水法繁体中文坤向说明中的单个简体字，避免结果卡片出现简繁混排。
- 修复三合八煞繁体说明仍直接使用简体知识库文本的问题，并修复 AR 繁体存证把原始简体宫名写入图片的问题。
- 修复一百二十分金繁体等级和秘诀文案中的孤虚、阴阳、财、针、祸等简体字残留。
- 统一繁体玄空格局、奇门导航/避忌方位、择日冲山和罗盘分金摘要使用本地化山名与方向，避免“兑/离”等原始简体字符泄漏。
- 修正玄空元运元信息中七运、九运卦名的繁体字段，避免 API 数据在非界面调用时仍返回简体“兑/离”。
- 优化传感器功耗：设备运动采样从 30Hz 调整为 20Hz，水准仪和磁场状态的 SwiftUI 发布分别限制为约 10Hz 与 5Hz，减少全页面连带重绘和抖动。
- 分析、户型和 AR 页面不再持续运行 Core Motion 俯仰/磁场采样；这些页面仍保留 Core Location 航向，运动传感器仅在罗盘和设置校准页使用。
- 设置页不再持续运行 Core Location 航向更新；切回罗盘、AR、户型或分析页时按页面需求恢复，保留定位和磁场校准数据以降低待机耗电。
- Core Motion 已在主队列回调中直接处理，不再为每个 20Hz 采样额外排队一次，降低传感器数据延迟和主线程堆积造成的界面抖动。
- 定位权限被撤销或限制时会清空旧经纬度、海拔和速度，并将真北回退到当前磁北后刷新罗盘状态，避免继续展示或导出过期定位数据。
- 天机长卷后台渲染前先在主线程固定朝向、坐标和真太阳时快照，避免报告内容来自不同传感器时刻或产生跨线程状态竞态。
- 主罗盘工具栏与顶部锁定按钮统一走 `CompassMotionManager.toggleLock()`，确保锁定操作遵循触觉开关和统一状态更新逻辑。
- 户型页切换语言时保留房间稳定 ID，并刷新当前已打开的房间详勘内容，避免弹窗继续显示切换前的语言或旧诊断。
- 修复 AR AI 扫描与存证拍摄的回调竞态：切换页面或请求被取消后的过期帧会被丢弃，AI 扫描和存证不会互相覆盖，也不会意外保存照片。
- AR 激光扫描动画现在只在 AR 页激活时运行，离开 Tab 会取消无限循环并复位，避免后台 Tab 持续触发界面重绘和额外耗电。
- 相机在来电/系统中断、运行时错误或切后台时会取消未完成的拍摄并回传失败，避免 AI 扫描无限等待和恢复后误处理过期帧。
- 户型诊断列表改用房间稳定标识，不再因罗盘角度更新生成全新 UUID，避免报告行反复重建、滚动位置抖动和无效布局开销。
- 减少航向状态无效广播：只有跨过 0.25° 或发生锁定姿态/手动拨盘变化时才更新九宫分析状态，真太阳时独立按秒刷新，航向代理回调限制为约 10Hz。
- 修复应用在设置、分析和户型页面仍强制保持屏幕常亮的问题；现在只有罗盘和 AR 页面保持常亮，切换页面或进入后台会恢复系统自动锁屏。

## 运行链路

- `SceneDelegate` 创建 `ViewController`，`ViewController` 承载 `RootContentView`；根视图包含罗盘、AR、户型、玄空分析和设置五个 Tab。
- `CompassMotionManager` 汇总 Core Location 航向/定位和 Core Motion 姿态/磁场数据，经过环形角度滤波后发布给 SwiftUI。罗盘盘面只旋转磁北盘，真北针单独叠加偏角。
- 各分析引擎（奇门、飞星、八宅、三合、天机等）是本地 Swift 计算，AR 使用 `AVCaptureSession`，截图由 UIKit 绘制水印。
- 会员流程由 `StoreKitIAPManager` 监听 StoreKit 1 交易队列，UI 通过 `VIPPaywallSheet` 和设置页购买/恢复权益。

## 已发现的主要问题

1. iOS 优先读取 `CLHeading.trueHeading`，定位暂不可用时使用 WMM 离线偏角作为后备，并在页面上区分真北与地磁北。
2. AR 页面原先只有按方位映射形煞的规则，没有图像分析；“AI 扫描”在 Web 版本是固定延时和固定结果，不能作为真实识别。
3. StoreKit 商品未返回时购买按钮没有稳定的失败状态；购买错误没有统一传给 SwiftUI，年度会员过期后仅在初始化时刷新；价格显示硬编码。
4. Web 收银台在没有原生桥时会写入本地“购买成功”状态，存在伪造权益的风险；数字内容应该只走 App Store In-App Purchase，不能把 Apple Pay 当成替代渠道。
5. AR 截图使用 `UIImageWriteToSavedPhotosAlbum`，不检查 Photos 权限和保存结果；相机会在页面生命周期切换时频繁重建，权限拒绝时只能显示仿真画板。

## 本次实现

- 新增 `Models/WorldMagneticModel.swift`：移植 WMM 2020-2025 13 阶系数和椭球坐标、Schmidt 准正规化、时间漂移解算，输出北/东/下分量、偏角、倾角和总场强。定位回调现在用同一份 WMM 结果驱动真北针，并保留 Core Location 真北作为首次定位前的兜底。
- 新增 `Models/OnDeviceShaAnalyzer.swift`：使用 Vision `VNDetectRectanglesRequest` 在设备端分析当前相机帧，按几何区域、长宽比和位置给出形煞候选、置信度和目标点；不上传图像、不需要网络或模型密钥。AR 页面新增扫描按钮并将结果映射到目标框。
- StoreKit 管理器增加商品加载、购买中、错误、完成状态，年度权益按已有到期时间顺延，前后台切换时重新计算过期权益；会员页面显示 App Store 本地化价格并呈现失败提示。
- Web 收银台移除无原生环境下的模拟购买成功逻辑，改为提示用户在原生 App 内通过 App Store 完成购买；页面文案统一为 StoreKit/App Store 内购。
- 截图改为 `PHPhotoLibrary` 授权后保存，并显示保存失败信息；工程链接 Vision 和 Photos framework。
- 完成全页面国际化审计：`LocalizationManager` 的简体、繁体、英文三套字典均为 370 个唯一 key，修复重复/缺失 key，并覆盖罗盘、户型、AR、奇门、八宅、分金和设置页的动态结果。
- 户型诊断、AR 形煞危害/古籍/化解、八路黄泉口诀、奇门九宫字段、节气、天机长卷标题与报告正文均根据当前语言输出；罗盘模型字段增加英文/繁体显示属性，避免页面直接渲染中文原始数据。
- 户型单次商品现在在首次导入户型图或打开房间详勘时实际扣减一次，同一页面会话内复用已取得的访问权；切换语言会刷新示例文案并保留用户拖拽后的房间位置。
- 户型图导入改为选图成功后才扣减额度，取消系统相册选择不会消耗权益；仅持有未使用额度时不会提前解锁整页示例详勘。
- 天机长卷和 AR 存图均通过 Photos `addOnly` 授权并检查 `performChanges` 结果，保存失败不会扣减天机权益，也会在页面显示失败提示。
