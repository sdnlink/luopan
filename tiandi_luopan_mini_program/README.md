# 演象 · 时空罗盘 - 微信小程序版

> **天地人合一 · 时空一体化数字易学罗盘**

本工程是 Android 原生时空罗盘（`tiandi_luopan`）的**完整原生移植**，与 Android 版 `yiijing_map.html` 在数据结构、算法与盘面布局上保持 1:1 对齐。

## 核心功能

### 1. 顶部综合状态栏（时间 · 速度 · 方向）
精简排版为 `21:50 · 0 KM/H · 正东 92°`。速度为 GPS 实时测速（KM/H），方向为八向粗方位 + 精确角度。

### 2. 先天 / 后天八卦双模式排盘
顶部 Tab 切换，盘面八宫文字、卦符与底部卦宫、五行属性同步联动。

### 3. 罗盘转动模式（盘随向转 / 固定盘面）
- **盘随向转**：盘面实时反向旋转，二十四山始终与现实地理空间绝对对齐，配合十字天心瞄准线读数；
- **固定盘面**：冻结盘面角度，便于稳定查看与推演。

### 4. 十字天心瞄准线（坐向同论）
贯穿盘心的红色十字丝，屏幕正前方为红色 ▲【向】，正后方为青色 ▼【坐】。底部实时显示 `坐酉向卯 · 正针` 立向格局。

### 5. 二十四山立向与空亡诊断
每山 15°，按偏离正中线度数分为四级，点击可查看详解弹窗：
- **正针纯清**（≤3.0°，绿）：丁财两旺；
- **兼向**（3.0°~6.0°，黄）：须起替卦；
- **小空亡**（同宫两山交界，红）：阴阳差错；
- **出卦大空亡**（两宫交界，深红）：极凶死线。

### 6. 一百二十分金吉凶断诀
360° 分 24 山、每山 5 分金，共 120 位，每位 3°。按天干判定：
- **旺相珠宝线**（丙、丁、庚、辛，金）：大吉；
- **龟甲火坑线**（戊、己，红）：大凶；
- **孤度**（甲、乙，橙）/ **虚度**（壬、癸，蓝）：不利。

> 盘面实现说明：120 分金每格仅占 3°，两字并排（切向排布）必然重叠糊成一团，
> 故分金干支采用**竖排**——两字沿半径方向堆叠，字身仍保持正立。
> 字号按「单字宽不超过 3° 弧长、两字总高不超过环宽」约束自动收敛（Android 版为切向）。

### 7. 双北指针系统与地磁偏角校准
- 绿色实线粗针（标「磁」）：地磁北（地盘正针）；
- 金色实线细针（标「真」）：地理真北（WMM 地磁模型 + GPS 校正）；
- 两针间金黄虚线弧标注当地磁偏角。

内置 WMM 2020-2025 世界地磁模型，纯 JS 离线解算，无需联网。`utils/geomagnetic.js` 是 Android
`GeomagneticField.java` 的完整 1:1 移植，一次解算输出**地磁七要素**：北向 X / 东向 Y / 垂向 Z、
磁偏角、磁倾角、水平强度、总场强度（面板中展示「地磁强度 / 磁倾角」）。

已用全球 10 座城市与物理极值点（地理/地磁南北极、地磁赤道）校验：

| 城市 | 模型磁偏角 | 参考值 |
|---|---|---|
| 纽约 | -12.48° | -12.6° |
| 波士顿 | -13.94° | -14.5° |
| 洛杉矶 | 11.26° | 11.5° |
| 西雅图 | 14.97° | 15.0° |
| 伦敦 | 1.34° | ~0° |
| 北京 | -7.88°（I=59.4°, F=55.0μT） | -7.3°（I≈59°, F≈54μT） |

### 7.1 陀螺仪角速度融合抗磁突变
对齐 Android `onSensorChanged` 的自适应滤波：读取物理陀螺仪真实角速度（rad/s，不受铁磁干扰），
据此动态调整朝向跟随权重——

| 状态 | 跟随权重 |
|---|---|
| 静止且磁场异常（贴近铁窗） | 0.05（极大压制磁吸偏） |
| 原地微停 | 0.20（沉稳平滑） |
| 常规旋转 | 0.40 |
| 快速转身（>0.4 rad/s） | 0.55（即转即随） |

> 小程序未开放原始磁通量（μT）接口，Android 的 `strength > 75 || < 20` 判据改用双路等效判定：
> 系统上报精度为 low/unreliable，或**陀螺仪判定静止但朝向仍突跳** >2.5°（典型磁吸偏特征）。

### 8. 电子双轴太极水准仪
内嵌于天心太极处：绿色虚线圈（2.5°）为精密平水合格圈，黄色圈（7.0°）为倾角警戒圈，气泡随实时横滚角 / 俯仰角位移。

### 9. 实时真太阳时日晷（黄色虚线金针）
 Spencer 日行差方程 + 经度时差修正，将北京时间校正为观测点视太阳时，用于八字判定时辰分界。

### 10. 四柱八字排盘
- 年柱以**立春定气交节**为界；
- 月柱以节气之「节」为界，年上起月五虎遁；
- 日柱以儒略日连续推算；
- 时柱按五鼠遁，且以**真太阳时**定时辰。

### 11. 先天六十四卦圆图与十二消息卦
最外环为邵雍先天六十四卦圆图（含六爻符号与卦名、八宫分界线），内圈为十二消息卦 + 六爻外环。

### 12. 多维度独立图层管理
点击【图层】可独立开关 7 个图层，并提供「全功能盘 / 三元分金盘 / 极简立向盘」三套预设：
太极水准气泡、八卦八宫环、二十四山、一百二十分金、二十四节气与消息卦、24 小时时间圈、先天六十四卦。

### 13. 强磁异常环境感应与预警
根据地磁传感器精度等级判定干扰，触发红色悬浮告警条。
> 小程序未提供原始磁通量（μT）接口，故以传感器精度等级等效替代 Android 的磁场强度判定。

### 14. 盘面缩放与平移手势
- 单指点击：选中该山向；
- 双指捏合：1.0x ~ 4.5x 无级缩放；
- 放大后单指拖拽：平移盘面（自动边界收敛）；
- 双击：在 1.0x 与 2.2x 之间切换。

缩放状态下自动关闭离屏位图缓存、改为矢量重绘，保证放大后文字与线条依然锐利。

## 性能架构

与 Android 版一致的三项优化：

1. **重绘合并与死区**：静态盘面（八宫 / 24 山 / 120 分金 / 节气 / 消息卦 / 时间刻度 / 64 卦，共 350+ 图元）采用 `requestAnimationFrame` 合并重绘，配合 0.05° 重绘死区，避免同一帧内多次绘制与无意义的重排。

   > 曾尝试用「移出视口的 DOM canvas」作离屏位图缓冲以进一步提速，但该方案在真机上会失效：
   > 移出视口的 canvas 不会被合成渲染，`drawImage` 到主画布得到的是全透明图且不抛异常，
   > 表现为真机罗盘完全空白（模拟器往往正常）。故改为直接矢量绘制。
   > 后续若需进一步优化，应使用官方 `wx.createOffscreenCanvas` 而非 DOM canvas。
2. **天文算力解耦**：四柱干支与真太阳时从 60Hz 旋转流剥离，1 秒定时运算并缓存，消除高频三角函数开销。
3. **死区防抖**：朝向信息卡片与风水状态设定 0.2° 变动死区，避免高频 `setData` 造成的视图层抖动。

## 启动性能优化：按需注入 + 用时注入

1. **按需注入**：`app.json` 中已配置 `"lazyCodeLoading": "requiredComponents"`。
   > 该字段必须写在 `app.json` 才生效；`project.config.json` 的 `setting.lazyCodeLoading` 只是开发者工具的本地开关。

2. **用时注入**：`pages/index/index.json` 为校准弹窗配置占位组件：

   ```json
   {
     "usingComponents": {
       "calib-modal": "/components/calib-modal/calib-modal"
     },
     "componentPlaceholder": {
       "calib-modal": "view"
     }
   }
   ```

   配合页面层的 `wx:if="{{showCalibModal}}"`，弹窗组件在用户首次点开前完全不进入渲染树，其 JS / WXML / WXSS 都不会被注入执行。

   > 基础库 2.11.1 起支持按需注入，2.11.2 起支持用时注入。建议将调试基础库调至 2.20.1 及以上。

## 权限说明

| 能力 | 接口 | 用途 |
|---|---|---|
| 定位 | `wx.getLocation` / `wx.startLocationUpdate` | 经纬度、海拔、地磁偏角、真太阳时经度修正、移动速度 |
| 罗盘 | `wx.startCompass` / `wx.onCompassChange` | 地磁北朝向与传感器精度 |
| 设备姿态 | `wx.startDeviceMotionListening` | 电子水准仪横滚角 / 俯仰角 |

`app.json` 中已声明 `permission.scope.userLocation` 与
`requiredPrivateInfos: ["getLocation", "onLocationChange", "startLocationUpdate"]`。

### 关于持续定位接口

`wx.startLocationUpdate` / `wx.onLocationChange` 属于需申请开通的受限接口。本项目**保留**
这两个接口的调用（用于实时刷新坐标与移动速度），前提是已在小程序后台完成开通：

1. 后台「开发」→「开发管理」→「接口设置」中自助开通 `wx.startLocationUpdate`；
2. `app.json` 的 `requiredPrivateInfos` 中已声明
   `"getLocation"`、`"onLocationChange"`、`"startLocationUpdate"` 三项。

> 注意：官方会在**代码审核环节**检测该接口是否已完成开通，未开通将拦截提审；
> 且 `requiredPrivateInfos` 只是「声明」、不等于「开通」，两者必须分别完成。

若因类目或权限未生效导致 `startLocationUpdate` 失败，代码会自动降级为
`wx.getLocation` 5 秒定时轮询（见 `startLocationWatch` 中的 `fallbackPoll`），功能不中断。

### 提审前检查清单

1. 确认后台「开发」→「开发管理」→「接口设置」中 `wx.startLocationUpdate` 处于**已开通**状态；
2. 小程序后台「设置」→「服务内容声明」→**用户隐私保护指引**中勾选「位置信息」，
   用途说明与 `app.json` 中 `scope.userLocation.desc` 保持一致；
3. 确认小程序**类目**与实际功能相符（罗盘类通常归入「工具」类目）；
4. 在真机上确认首次进入时位置授权弹窗正常弹出，拒绝授权后不崩溃、有明确提示。

## 分享能力

支持通过右上角菜单分享：

| 场景 | 回调 | 说明 |
|---|---|---|
| 发送给朋友 / 群聊 | `onShareAppMessage` | 封面为**当前罗盘画面**，经 `promise` 异步导出（基础库 2.12.0+，低版本自动回退默认截图） |
| 分享到朋友圈 | `onShareTimeline` | 基础库 2.11.3+，**目前仅 Android 支持**；该回调必须同步返回，故使用预生成的缓存图 |

**入口**：

- **分享给好友**：页面功能栏的「📤 分享」按钮（`open-type="share"`），或右上角菜单「发送给朋友」
- **分享到朋友圈**：仅右上角菜单「分享到朋友圈」——微信未提供对应的 `button open-type`，
  无法用按钮直接触发朋友圈分享

实现要点：

1. `onLoad` 中调用 `wx.showShareMenu({ menus: ['shareAppMessage', 'shareTimeline'] })`。
   注意：只有定义了 `onShareTimeline`，右上角菜单才会出现「分享到朋友圈」；
   且显示朋友圈按钮时必须同时显示好友按钮，反之则允许只显示好友按钮。
2. `onReady` 后延迟 2 秒导出一次罗盘画面缓存，供朋友圈分享同步返回；
   每次分享时会再异步刷新一次缓存，使下次分享用上最新画面。
3. 画布在弹窗打开时会被 `hidden` 隐藏，此时导出会得到空白图，导出前会检查并跳过。
4. 分享标题在能取到今日当令之山时形如「演象·时空罗盘 · 今日主应 壬山」，否则回退固定描述。

> 分享图为正方形画布，正合朋友圈 1:1 展示比例；好友分享按 5:4 居中裁剪，
> 盘面为圆形且居中，裁剪影响很小。

## 全屏显示与顶部标题

`app.json` 与 `pages/index/index.json` 均设置 `"navigationStyle": "custom"`，
移除系统导航栏，页面内容从屏幕顶部开始渲染。
（系统状态栏为原生渲染，任何方式都无法隐藏。）

标题「演象 · 时空罗盘」由页面自行绘制（`.custom-nav`），并做了两处适配：

1. **顶部**：`padding-top` 由 JS 按 `wx.getWindowInfo().statusBarHeight` 动态注入，
   避免标题被系统状态栏遮挡。刘海屏、挖孔屏的状态栏高度各不相同，不能写死。
2. **底部**：`padding-bottom` 叠加 `env(safe-area-inset-bottom)`，
   避免全面屏机型的 Home Indicator 遮挡底部信息面板。

> 右上角胶囊按钮由微信原生渲染，**无法通过 `custom` 模式隐藏**，
> 因此标题保持居中，与右侧胶囊共存。

## 导入与调试指南

1. 打开 **微信开发者工具**；
2. 点击 **「导入项目」**；
3. **项目目录**：选择本目录（即本 README 所在目录，例如 `E:\code\android\tiandi_luopan_mini_program`）；
4. **AppID**：测试阶段可选「测试号」或填入自己的 AppID；
5. 点击 **「真机调试」** 或 **「预览」**，扫码即可体验陀螺仪、地磁双针与水准仪。

> 指南针与水准气泡依赖真实硬件传感器，请使用真机验证；开发者工具模拟器中罗盘与姿态数据不可用。
